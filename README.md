# Programação Modular
 
Repositório destinado às atividades, exercícios e projetos desenvolvidos na disciplina de **Programação Modular**.
 
## 📚 Organização
 
As atividades estão organizadas por listas e exercícios:
 
```
prog_modular/
│
├── Lista00/
│   ├── ex01/
│   ├── ex02/
│   ├── ex03/
│   └── ...
│
└── README.md
```
 
Cada exercício possui seus próprios arquivos e código-fonte.
 
## 📝 Listas
 
### Lista 00
 
Exercícios envolvendo os fundamentos da programação em Java, incluindo:
 
- Estruturas condicionais;
- Estruturas de repetição;
- Vetores;
- Matrizes;
- Manipulação de dados;
- Cálculos e processamento de informações.

## 💻 Tecnologias

- Java
- JDK
- Git
- GitHub
  
## 🌿 Branches

Os exercícios podem ser desenvolvidos em branches individuais, seguindo o padrão:

```
lista00-ex01
lista00-ex02
lista00-ex03
...
```
 
A branch `main` contém a versão principal e organizada do repositório.
 
## 🎯 Objetivo
 
Este repositório tem como objetivo reunir e organizar o desenvolvimento das atividades da disciplina de Programação Modular, permitindo acompanhar a evolução dos exercícios e dos conceitos aprendidos ao longo da disciplina.
